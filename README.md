# Portfolio - Panduga Manoj Kumar

> A personal portfolio website built with Astro, React, and Tailwind CSS.

## Tech Stack

- **Framework:** Astro
- **UI:** React with TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## Getting Started

```bash
npm install
npm run dev
```

## Customization

- **Content:** Edit components in `src/components/`
- **Metadata:** Update `src/layouts/Layout.astro`
- **Projects:** Edit the project list in `src/components/projects.astro`
